# /cosmos: the engine behind this profile

Every image on this profile is generated by the zero-dependency Node scripts in this folder, and every number in them is live. No services, no npm installs, no image APIs: just SVG, CSS and a little math.

| file | what it does |
| --- | --- |
| `fetch.mjs` | pulls live data into `stats.json`: @aipulseda1ly followers, posts and post stats from X (public FxTwitter API), every new model and its price from OpenRouter's public model list, and the contribution calendar from GitHub |
| `build.mjs` | renders every SVG and the live parts of the README from `stats.json`, `signals.json` and `votes.json` |
| `signal.mjs` | handles the two interactive features: a `📡 signal` issue plants a visitor as a star, a `vote: <model>` issue counts a vote |
| `poll.mjs` | builds the ballot (the newest models from the big labs that have not faced the NYC test yet) and tallies votes |
| `aipulse.json` | the fixed facts: the X handle, which posts to track, the NYC test brief and the poll settings (no numbers live here) |
| `art-pulse.mjs` | the aipulsedaily side: hero, follow button, the pulse, the NYC test, the price chart, the vote |
| `art-*.mjs` | the other scenes: terminal, mission patches, guestbook, commit galaxy, star chart, headers, footer |
| `kit.mjs` | tiny SVG toolkit: text is drawn as real glyph outlines (`glyphs.json`, from OFL fonts) so it renders the same everywhere |
| `derive.mjs` | streaks, best day, growth and friends for the commit galaxy |

Two workflows keep it alive. `cosmos · live sync` runs every 15 minutes (and on every push) and commits only when something visible changed. `cosmos · incoming signal` runs whenever someone transmits a signal or votes.

Run it locally: `node cosmos/build.mjs` (Node 18+).

Fonts: Michroma, Orbitron, JetBrains Mono and Space Grotesk, all under the SIL Open Font License, embedded as outlines.
