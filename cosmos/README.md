# /cosmos — the engine behind this profile

Every image on my profile is generated by the zero-dependency Node scripts in this folder. No services, no npm installs, no external image APIs: just SVG, CSS and a little math.

| file | what it does |
| --- | --- |
| `fetch.mjs` | pulls live telemetry (contribution calendar, yearly totals, mission stats) from the GitHub API into `stats.json` |
| `build.mjs` | renders every SVG + the live parts of the README from `stats.json` and `signals.json` |
| `signal.mjs` | plants a visitor as a star when they open a `📡 signal` issue |
| `art-*.mjs` | the scenes: hero, terminal, commit galaxy, star system, mission patches, guestbook, footer |
| `kit.mjs` | tiny SVG toolkit — text is drawn as real glyph outlines (`glyphs.json`, from OFL fonts) so it renders identically everywhere |
| `derive.mjs` | streaks, best day, growth and friends |
| `stl.mjs` | the 3D skyline you can spin in the README |

Two workflows keep it alive: `cosmos · telemetry sync` (daily, and on every push) and `cosmos · incoming signal` (whenever someone transmits).

Run it locally: `node cosmos/build.mjs` (Node 18+).

Fonts: Michroma, Orbitron, JetBrains Mono and Space Grotesk, all under the SIL Open Font License, embedded as outlines.
